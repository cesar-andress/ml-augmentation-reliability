# Repository policy

Binding project rules for this reproducibility repository.

1. `main` is the only permitted branch.
2. All commits are made directly to `main`.
3. No additional branches may be created for normal project work.
4. No force pushes.
5. No rewriting history after scientific freezes.
6. The manuscript lives outside this repository at `~/papers/ml/paper`.
7. Manuscript files must never be copied, staged, committed, pushed, released, or archived from this repository.
8. This repository contains only the reproducibility artifact.
9. Its eventual archival target is Zenodo.
10. GitHub releases and Zenodo actions require explicit user instruction.
11. Scientific freeze provenance must always preserve: original monorepo freeze commit, publication commit, and cohort SHA256.

This is project policy. Git cannot technically prevent every local branch creation; collaborators must follow these rules.
